# Worldbuilding

An OpenKnowledge starter pack for fiction projects: an encyclopedia of
characters, settings, factions, and lore, kept consistent while the story
changes around it.

## Skills

| Skill | What it does |
|---|---|
| `worldbuilding` | How to work in this project: one dossier per entity, canon vs. draft status, and keeping cross-references consistent when a character or place changes. |

## Install

- Seed a project: `ok seed --pack worldbuilding`
- Claude Code plugin: `/plugin install worldbuilding@open-knowledge-skills`
