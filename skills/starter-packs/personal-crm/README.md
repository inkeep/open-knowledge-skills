# Personal CRM (entity-vault)

An OpenKnowledge starter pack for a typed-entity vault: people, companies,
meetings, and concepts, each a dossier with a rewritable summary plus an
append-only timeline. GBrain-compatible.

The pack's seed id is `entity-vault`; the skill it ships is named
`personal-crm`, matching what the project actually is.

## Skills

| Skill | What it does |
|---|---|
| `personal-crm` | How to work the vault: capture notes about a person or company, log meetings, prep for upcoming ones, and answer "who is this and what was last said" from the dossiers. |

## Install

- Seed a project: `ok seed --pack entity-vault`
- Claude Code plugin: `/plugin install personal-crm@open-knowledge-skills`
