# Plain Notes

The simplest OpenKnowledge starter pack: a flat `notes/` folder plus a daily
journal. No taxonomy to maintain and nothing to file. Write things down; links
and search do the organizing. The pack's seed id is `plain-notes`; the skill it
ships is named `note-taking`.

## Skills

| Skill | What it does |
|---|---|
| `note-taking` | How to capture notes and journal entries in this project: where new notes land, how the daily journal works, and how to link notes into the graph instead of filing them into folders. |

## Install

- Seed a project (folders, templates, and the skill together): `ok seed --pack plain-notes`
- Claude Code plugin: `/plugin install note-taking@open-knowledge-skills`

The skill assumes the pack's folder layout exists, so seeding is the primary
path; the plugin channel is for adding the skill to an already-seeded project.
