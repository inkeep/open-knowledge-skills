# Writing Pipeline

An OpenKnowledge starter pack for publishing workflows: ideas move through
drafts to published pieces, and the project's folder layout is the pipeline.
The pack's seed id is `writing-pipeline`; the skill it ships is named
`writing-workflow`.

## Skills

| Skill | What it does |
|---|---|
| `writing-workflow` | How to move a piece through the pipeline: capturing ideas, promoting an idea to a draft, revising, and marking a piece published without losing its history. |

## Install

- Seed a project: `ok seed --pack writing-pipeline`
- Claude Code plugin: `/plugin install writing-workflow@open-knowledge-skills`
